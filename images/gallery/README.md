# Gallery photos

Drop real photos into this folder using the exact filenames below and they
replace the gradient + emoji placeholders automatically — no code changes
needed (see `js/gallery.js`, which already points at these paths).

Recommended: landscape JPGs, ~1600px on the long edge, optimized/compressed
(under ~300KB each keeps the gallery fast).

| Filename                              | Replaces placeholder for            |
|----------------------------------------|--------------------------------------|
| `sunset-skyline-view.jpg`              | Sunset Skyline View                  |
| `spicy-margarita-on-marble.jpg`        | Spicy Margarita on Marble            |
| `lounge-seating-patio-heaters.jpg`     | Lounge Seating & Patio Heaters       |
| `long-table-set-for-celebration.jpg`   | Long Table, Set for Celebration      |
| `city-lights-at-night.jpg`             | City Lights at Night                 |
| `sharing-plates-small-bites.jpg`       | Sharing Plates & Small Bites         |
| `18th-floor-balcony-greenery.jpg`      | 18th-Floor Balcony Greenery          |
| `live-dj-sunset-set.jpg`               | Live DJ Sunset Set                   |
| `bar-mixology-bench.jpg`               | Bar & Mixology Bench                 |
| `grilled-seafood-platter.jpg`          | Grilled Seafood Platter              |
| `golden-hour-cappuccino.jpg`           | Golden Hour Cappuccino               |
| `270-panorama-at-dusk.jpg`             | 270° Panorama at Dusk                |

You don't need all twelve at once — any filename you add shows up
immediately; the rest keep showing their placeholder until you add them too.
