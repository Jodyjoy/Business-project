# Hero photos

Drop a real photo into this folder using the filenames below and it
replaces that page's abstract gradient background automatically — no code
changes needed. A dark scrim is applied automatically on top so the
headline text stays readable over any photo.

Recommended: landscape JPGs, ~1920px on the long edge, optimized/compressed
(under ~400KB each), since these are the largest images on each page.

| Filename        | Used on          |
|------------------|-------------------|
| `home.jpg`       | Home hero (full-bleed) |
| `about.jpg`      | Experience page hero |
| `menu.jpg`       | Menu page hero |
| `gallery.jpg`    | Gallery page hero |
| `reviews.jpg`    | Reviews page hero |
| `reserve.jpg`    | Reserve page hero |
| `visit.jpg`      | Visit page hero |

Add them one at a time — pages without a matching file keep their current
gradient look until you do.
